# AI Context

Stable reference that many prompts need: architecture, repo layout, coding conventions.

## What loads when

- `architecture.md` and `coding-standards.md` are imported into `CLAUDE.md`, so they load every session. Keep them short.
- `repo-map.md` and `medusa-dev-notes.md` are read only when something points Claude to them.

Keep these files short, current, and broadly useful. Feature plans and one-off notes don't belong here.
